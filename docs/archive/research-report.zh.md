# 小农场智能化设备选择与聊天平台调研报告

## 1. 优先支持的设备

小规模温室需要先解决**通风和灌溉**，其次是监测与光照等功能。综合文献、行业案例以及小农户反馈，可以总结出以下优先级。

### 1.1 温湿度和环境监测

智能温室的第一步是监测。当不能看到温度、湿度变化时，就无法及时调整。带有 Wi-Fi 的温度计、湿度计可以实时查看温室状况、设置警报阈值、查看历史数据。高隧道温室资料也强调应通过监测避免只依赖经验判断。

### 1.2 自动通风 / 卷膜系统

通风是维持温室微气候的关键。调研中反复出现的痛点是：温室主需要在突然升温、阴晴变化、早晚温差大的时候频繁开关侧帘或通风口。

自动屋顶通风口、自动侧卷膜、卷帘电机适合优先支持。它们能与温度传感器联动，在温度升高时自动开棚，在温度下降后自动关闭，从而降低人工干预和作物受损风险。

### 1.3 排风扇 / 风机

为加快空气交换，小型高隧道温室通常在一端安装排风扇，另一端设通风口或百叶窗。排风扇与通风口结合能加速空气流动，尤其适合夏季高温、高湿场景。

在一些小农场案例中，一个控制单元可同时驱动多个温室的风机，并配合卷帘侧壁保持温度和湿度稳定。

### 1.4 智能灌溉系统：水泵 / 电磁阀

普通灌溉定时器按固定时间开关，容易出现过度浇水或高温时缺水。基于天气数据、土壤湿度传感器或人工指令的智能灌溉系统，可以远程管理并自动调整灌溉。

在精耕作物，如草莓、番茄、花卉、育苗等场景中，水泵、电磁阀与土壤湿度传感器联动具有较高价值。

### 1.5 照明和加热控制，可选

在昼短季节、育苗场景或高价值作物种植中，需要补光或加热。补光灯可通过定时器或光照传感器保持稳定光周期；加热系统主要用于寒冷地区，应配合恒温器和安全保护。

这类设备有价值，但不建议放在 MVP 第一优先级。

### 1.6 安全与监控设备，可选

摄像头和运动传感器可用于远程查看温室设备运行状态、防盗、防误操作确认。它们适合后续作为增值模块加入。

### 1.7 初始结论

首批支持的硬件应该是：

1. 温湿度传感器
2. 自动卷膜电机 / 通风控制
3. 排风扇 / 风机
4. 水泵 / 电磁阀控制器

必须配备必要的安全保护：限位开关、手动优先、运行超时、断网保护、互锁保护、熔断器和操作日志。

照明、加热、摄像头、NDVI、农资管理等功能可作为第二阶段扩展。

## 2. 部署规模与控制点

智能化系统的投资回报取决于温室数量和控制点数量。文献与案例显示，小农户通常有以下特征。

### 2.1 温室数量

很多小农场拥有数个高隧道温室或塑料大棚。案例中常见规模包括：

- 2 座高隧道温室，共用一个控制单元控制风机或通风设备；
- 6–8 座温室，通过多个控制单元实现自动卷膜和风机控制；
- 家庭农场或花卉农场通常更关心每天早晚是否需要人工开关棚。

因此，MVP 阶段建议面向 **2–4 座温室** 的小农场，后续可扩展到 8 座或更多。

### 2.2 每座温室的控制点

每座温室一般可按 3–5 个控制点设计：

- 卷膜控制器：1–2 个，取决于是否左右侧帘分别控制；
- 风机控制器：1–2 个，取决于温室大小和换气需求；
- 灌溉控制：1 个主水泵或 1–4 个分区电磁阀；
- 扩展控制：加热、补光、喷雾、湿帘、施肥泵等。

### 2.3 MVP 规模建议

MVP 阶段建议设计为：

```text
2–4 座温室
每座温室 1 个环境传感器节点
每座温室 3–5 个控制点
总控制点约 6–20 个
```

这个规模足以验证客户价值，也不会让硬件和售后复杂度过高。

## 3. 硬件选型与网络接口

硬件层建议基于 ESP32 或类似低功耗控制器，并结合继电器、H 桥驱动器或接触器完成设备控制。网络上建议同时支持 Wi-Fi 和有线以太网。

### 3.1 主控板

推荐方向：

- ESP32 系列：低成本，自带 Wi-Fi 和蓝牙，生态成熟；
- ESP32 Ethernet Kit 或带 LAN8720 / W5500 / IP101 PHY 的以太网开发板：支持 RJ-45 有线连接；
- 带 PoE 能力的版本可减少现场供电复杂度，但成本更高，可作为后续版本。

### 3.2 驱动与执行器

不同设备建议使用不同驱动方式：

- 24V DC 卷膜电机：使用 BTS7960 或更工业化的 H 桥驱动器；
- AC 风机 / 水泵：使用固态继电器、交流接触器或工业继电器模块；
- 电磁阀：使用 12V / 24V 继电器或 MOS 管驱动；
- 需要正反转的电机必须加入方向互锁与限位保护。

### 3.3 传感器

MVP 可选：

- 温湿度传感器：SHT31、SHT35、DHT22，优先工业稳定版本；
- 土壤湿度传感器：电容式土壤湿度传感器，或 RS-485 土壤水分传感器；
- 光照传感器：BH1750 或工业光照传感器；
- 后续可加风雨传感器、CO2、EC、pH、摄像头等。

### 3.4 网络连接

建议硬件同时支持：

- Wi-Fi：适合低成本、布线困难的温室；
- Ethernet：适合固定场地、需要稳定连接的温室；
- 4G：作为弱网或偏远地区的后续版本；
- LoRa / 433MHz：适合多棚分布较远、但控制中心固定的场景。

MVP 可以先实现 Wi-Fi + Ethernet，4G 和 LoRa 后续再做。

## 4. 聊天平台支持策略

### 4.1 国内市场

国内平台建议按以下顺序支持：

1. 微信 / 微信小程序
2. 企业微信
3. 飞书
4. 钉钉，可选

微信适合农户和老板日常使用，企业微信适合团队、合作社、基地管理，飞书适合年轻团队和跨境团队。

### 4.2 海外市场

海外市场建议优先支持：

1. WhatsApp Business
2. Facebook Messenger
3. LINE
4. Telegram
5. Lark
6. KakaoTalk，面向韩国
7. Zalo，面向越南

其中，WhatsApp 在欧洲、拉美、印度、东南亚、非洲等地区覆盖面最大；LINE 适合日本、台湾、泰国；KakaoTalk 适合韩国；Zalo 适合越南；Telegram 适合技术用户和部分国家市场。

### 4.3 统一聊天入口设计

建议不要为每个平台写一套业务逻辑，而是抽象为统一的聊天网关：

```text
微信 / 企业微信 / LINE / WhatsApp / Messenger / Telegram
  ↓
聊天网关
  ↓
意图解析
  ↓
技能路由
  ↓
安全保护
  ↓
设备指令服务
```

这样不同平台只负责消息收发，核心业务逻辑保持统一。

## 5. MVP 阶段实施建议

### 5.1 MVP 目标

MVP 不做完整智慧农业平台，只验证一个闭环：

```text
看温度 → 判断异常 → 建议动作 → 人工确认 → 控制设备 → 记录结果 → 异常提醒
```

### 5.2 MVP 功能列表

第一版建议只做以下功能：

1. 查询温湿度
2. 高温 / 低温 / 高湿报警
3. 开 / 关 / 停卷膜电机
4. 开 / 关风机
5. 开 / 关水泵或电磁阀
6. 操作日志
7. 设备离线提醒
8. 手动优先和安全保护
9. 微信 / 企业微信机器人入口

### 5.3 技能设计

自然语言不应直接调用硬件接口，而是由 **LLM 唯一**映射到预定义技能（MVP 不使用意图层正则回退）；校验后进入确定性安全层执行：

```text
greenhouse.query_status
greenhouse.open_vent
greenhouse.close_vent
greenhouse.stop_vent
fan.start
fan.stop
irrigation.start
irrigation.stop
alert.set_threshold
log.query
```

每个技能内部再做权限校验、安全检查、参数限制、设备状态检查和执行记录。

### 5.4 安全策略

所有物理控制必须满足：

- 手动开关优先级最高；
- 卷膜电机正反转互锁；
- 单次动作最大运行时长限制；
- 限位开关保护；
- 断网不继续执行危险动作；
- 异常状态自动停止；
- 高风险动作二次确认；
- 所有操作写入日志。

### 5.5 推荐系统架构

```text
聊天平台
  ↓
Webhook / 机器人网关
  ↓
LLM 意图解析
  ↓
技能路由
  ↓
权限与安全保护
  ↓
设备指令服务
  ↓
MQTT / HTTP / WebSocket
  ↓
ESP32 网关
  ↓
传感器 / 电机 / 风机 / 水泵 / 继电器
```

核心原则：LLM 只负责理解语言和生成结构化意图，不直接操作硬件。

## 6. 阶段路线图

### 阶段 0：需求验证

- 找 3–5 个真实种植户访谈；
- 确认是否有卷膜电机、水泵、风机等现有设备；
- 确认他们现在怎么开关棚、怎么报警、怎么记录。

### 阶段 1：MVP

- 支持 1–2 座温室；
- 支持温湿度监测、卷膜、电机停止、风机、水泵；
- 接入微信 / 企业微信；
- 实现日志和报警。

### 阶段 2：小规模试点

- 支持 2–4 座温室；
- 加入分组控制、定时任务、日报；
- 加入更稳定的硬件外壳、防水、防雷和安装手册。

### 阶段 3：商业化版本

- 支持多租户；
- 支持 WhatsApp / LINE / Messenger；
- 支持设备管理后台；
- 支持农事任务、农资记录、巡棚记录。

### 阶段 4：高级能力

- NDVI 地图；
- 病虫害识别；
- 产量与操作复盘；
- 智能农事建议；
- 和农场数据库 / ERP 集成。

## 7. 总结

小农场的核心痛点在于劳动力不足、频繁手动操作、缺乏远程监测和操作留痕。调研显示，温湿度监测、自动通风、风机和智能灌溉是初期自动化的核心。

最现实的 MVP 不是“智慧农业大平台”，而是一个小而硬的闭环：

```text
温室数字工长：微信里查温度、开风口、控水泵、收报警、留日志。
```

硬件上建议选择 ESP32 + Wi-Fi / Ethernet + 继电器 / 电机驱动器；软件上采用聊天平台 + LLM 意图解析 + 预定义技能 + 安全执行层。这样能以低成本快速落地，并为后续的农场数据库、任务系统、NDVI 和 AI 农事助手奠定基础。
