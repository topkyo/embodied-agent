四层底座

不是聊天机器人，也不是普通 IoT 看板。

会理解的 Agent、在现场执行的 Node、可复盘的 Skills、持续沉淀的 Memory —— 四层缺一不可。

01 Agent

云端大脑

听懂自然语言，输出可执行意图；危险动作有安全护栏。

02 Node

场景身体

传感、继电器、风机在边缘执行；超时与互锁本地裁决。硬件 →

03 Skills

场景技能

带确认策略、风险等级和观察窗口，不是裸 API。

04 Memory

动作沉淀

指令日志与 outcome 复盘，让下一轮建议更贴近现场。

物理闭环

从一句指令，到一次可审计的现场动作。

LLM 只提案，不静默接管设备。每一环有记录，出事能追溯。

01IM / 语音

用户用熟悉的方式说话。

02结构化意图

识别做什么、做多久、对哪台设备。

03安全裁判

权限、确认、互锁、时长逐项检查。

04Node 执行

现场节点执行或拒绝。

05状态上报

温湿度、设备状态与命令事件持续回传。

06效果复盘

动作是否达到预期，自动留痕可审计。
