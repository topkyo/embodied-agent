日常入口

微信就是你的操作台。

查棚、确认通风、收报警 — 棚主日常都在微信完成。装设备、配账号走运维台。

01

扫码添加场景助手

微信扫右侧码，添加「守棚工长」等场景助手。没绑定前，助手只会提示你先完成绑定。

02

输入安装人员给的配对码

配对码把你的微信和农场账号连起来，并决定你是棚主还是现场工人。

03

像聊天一样下指令

「1 号棚现在几度？」— 查询直接回复；开风机、开通风等动作，按风险等级要你确认后才执行。

01

进入平台底座

配置大模型 Key、MQTT、deployment_id，完成节点配对。绑定真源在平台底座，不在本页。

02

创建用户并签发配对码

在「用户与绑定」页创建棚主/工人账号，生成配对码供扫码绑定。

03

验证模拟闭环

确认 active deployment 节点在线，待确认动作能完整闭环。演示数据须标注「模拟」。
