# 叠加层安装 Checklist

**农场：** _______________　**日期：** _______________　**安装人：** _______________

## 安装前

- [ ] 与老板确认：仅接 **1–2 个控制点** + 1 路温湿度（不扩范围）
- [ ] 断电窗口已约定，现场有人监护
- [ ] 已有控棚方式已记录（定时器 / PLC / 一体机）：_______________
- [ ] 手动开关/急停可物理切断负载

## 接线与 Scene Node

- [ ] Scene Node 已配 Wi-Fi / 网络，MQTT 连上云端（broker 绿灯）
- [ ] 温湿度读数在云端可见
- [ ] 通风（侧帘/卷膜）**开 / 停** 各测 1 次，边缘超时自动停
- [ ] （可选）风机开/停各测 1 次
- [ ] 未破坏原 PLC/一体机安全链（叠加而非替换）

## 手动优先

- [ ] 现场手动操作后，云端开棚指令被拒绝并有中文提示
- [ ] 向老板说明：人在现场手动时，微信不会抢控

## 微信试控（自然语言 3 条）

使用日常说法，非固定口令：

1. [ ] 「___号棚现在多少度？」→ 回复含温湿度
2. [ ] 「把 ___ 号棚打开 ___ 分钟」→ 回复已开始，日志有记录
3. [ ] 「停止 ___ 号棚通风」→ 回复已停止

## 报警

- [ ] 阈值报警试 1 次（模拟或真实超温），老板微信收到提醒

## 交付

- [ ] 老板知悉 4–8 周免费范围与毕业看「少跑棚」
- [ ] 内部棚位 ID 与别名写入设备注册：`gh-001` = ______
