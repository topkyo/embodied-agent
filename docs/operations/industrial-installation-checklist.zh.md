## 试控（自然语言 3 条）

使用日常说法，非固定口令：

1. [ ] 「机房 / ___ 点现在多少度？」→ 回复含温度
2. [ ] 「确认后启动 ___ 排风 ___ 分钟」→ 出现确认步骤，确认后开始，日志有记录
3. [ ] 「停止 ___ 排风」→ 回复已停止

## 确认门

- [ ] 高风险动作（启动排风等）必须出现确认步骤，未确认不得执行
