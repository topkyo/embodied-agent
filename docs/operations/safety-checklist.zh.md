# 安全检查清单

具身Agent 会控制真实的现场设备。安全必须作为一等系统需求处理，不能作为后补项。

## 当前使用方式

本文档是**真实设备接入前**的现场验收清单，不代表所有条目都已在真实温室验证完成。当前云端、模拟器和 ESP32 DRY_RUN 原型已通过工程测试；接真实电机前仍必须完成假负载、手动优先、互锁、离线和断电窗口验证。

**实现边界（2026-06-19）：** 云端 `packages/safety` 已实现 RBAC、时长上限、通风方向互锁（基于 command store）、二次确认、心跳离线判断；`manual_override` 当前来自 registry 静态字段。v0.7.0：token 比较改 constant-time（safeEqualString）；MQTT malformed JSON 改 log.warn + 自动重连；全局 setErrorHandler 屏蔽 5xx 内部细节；生产强制 AGENT_DATA_DIR。**限位开关、急停、边缘独立超时**须在固件/GPIO 层实现并在现场验收，云端 guard 不替代边缘硬保护。

## 核心规则

> LLM 可以理解语言，但只有经过确定性安全检查的技能可以操作硬件。

## 物理安全

### 手动优先

- [ ] 每台受控设备都有本地手动控制方式。
- [ ] 手动控制优先级高于云端控制。
- [ ] Scene Node 在可行时能检测手动状态。
- [ ] 手动状态生效时，云端指令应被拒绝或暂停。

### 电机方向互锁

针对卷膜侧帘电机和其他可正反转电机：

- [ ] 打开和关闭方向不能同时激活。
- [ ] 方向切换前需要短暂的中位延迟。
- [ ] 相反方向仍在运行时拒绝新指令。
- [ ] 设备重启后电机输出默认关闭。

### 运行时长限制

- [ ] 每个物理动作都有最大运行时长。
- [ ] Scene Node 独立于云端状态执行本地超时。
- [ ] 云端服务也会限制最大时长。
- [ ] 未指定时长的有时长控制指令必须拒绝或澄清；无时长动作须由 skill schema 显式声明。

### 限位开关

- [ ] 在可行时支持打开限位开关。
- [ ] 在可行时支持关闭限位开关。
- [ ] 指令执行前检查限位状态。
- [ ] 限位开关触发后立即停止电机。

### 电气安全

- [ ] 继电器、接触器和驱动器额定能力高于实际负载。
- [ ] 安装熔断器或断路器保护。
- [ ] 高压交流线与低压信号线分离布线。
- [ ] 温室部署使用防水外壳。
- [ ] 户外布线考虑接地和浪涌保护。

### 网络故障行为

- [ ] 连接丢失时设备停止危险动作。
- [ ] 云端不可达时，Scene Node 仍执行本地超时。
- [ ] 心跳超时后上报离线状态。
- [ ] 重新连接后，云端不能重复发送过期指令。

## 软件安全

### 权限控制

- [ ] 用户映射到角色。
- [ ] 角色定义查询、控制、管理和急停权限。
- [ ] 未知用户不能控制设备。
- [ ] 群聊场景必须校验具体发送者身份。

### 确认策略

以下指令应要求二次确认：

- [ ] 控制所有温室。
- [ ] 设备运行时间长于二次确认阈值或 Domain Pack 显式时长策略。
- [ ] 修改报警阈值。
- [ ] 关闭报警。
- [ ] 同时启动多个分区灌溉。
- [ ] 打开或关闭所有通风口。

### 结构校验

- [ ] 所有 LLM 输出都按 JSON 解析。
- [ ] 输出必须匹配技能结构。
- [ ] 未知技能应被拒绝。
- [ ] 未知目标应被拒绝。
- [ ] 缺少参数时触发澄清。
- [ ] 置信度低于阈值时触发澄清。

### 指令生命周期

每条指令应具备以下状态：

```text
created → sent → acknowledged / running → completed
              ↘ failed / timeout / rejected
```

检查项：

- [ ] 每条指令都有唯一指令 ID。
- [ ] 每条指令都有幂等键。
- [ ] 指令会在较短 TTL 后过期。
- [ ] 设备拒绝过期指令。
- [ ] 重复指令不会造成重复的危险动作。

## 数据与审计

### 操作日志

每个物理动作都必须记录：

- [ ] 用户 ID
- [ ] 聊天平台
- [ ] 会话 ID
- [ ] 原始消息
- [ ] 解析后的技能
- [ ] 设备 ID
- [ ] 参数
- [ ] 安全决策
- [ ] 开始时间
- [ ] 结束时间
- [ ] 结果
- [ ] 错误原因，如有

### 遥测日志

- [ ] 传感器读数包含时间戳和设备 ID。
- [ ] 遥测数据以足够精度存储，便于排查问题。
- [ ] 记录设备心跳。
- [ ] 心跳缺失后生成离线报警。

## Scene Node 安全

Scene Node 应执行：

- [ ] 本地最大运行时长限制。
- [ ] 电机互锁。
- [ ] 限位停止。
- [ ] 安全启动状态。
- [ ] 看门狗定时器。
- [ ] 指令 TTL。
- [ ] 急停。
- [ ] 手动优先检测。
- [ ] 本地状态上报。

## MVP 验收标准

在以下条件达成前，MVP 不应进入真实温室测试：

- [ ] 模拟设备测试通过。
- [ ] 本地超时已测试。
- [ ] 电机互锁已测试。
- [ ] 手动优先行为已测试。
- [ ] 离线行为已测试。
- [ ] 操作日志完整。
- [ ] 含糊指令会被拒绝。
- [ ] 高风险指令需要二次确认。

## 不可妥协原则

1. 不允许 LLM 直接控制硬件。
2. 未经技能校验不允许执行物理动作。
3. 没有超时保护不允许控制电机。
4. 没有互锁保护不允许控制可正反转电机。
5. 没有本地手动控制不允许远程控制。
6. 不允许静默执行，必须向用户反馈。
7. 不允许未记录的物理动作。
